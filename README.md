# SPEC Website

Official website for the UBC Sports & Enhancement Club (SPEC), built to showcase the club, upcoming events, team, sponsors, and ways to get involved.

## Live Site

https://specwebsite-t79j.vercel.app/

## About SPEC

SPEC is a UBC student club focused on helping students stay active, meet people, and make university more memorable through sports, outdoor activities, social events, and community experiences.

## Website Features

- Responsive landing page centered around the SPEC brand
- Animated spinning SPEC logo background
- About section introducing the club and its community
- Upcoming events / calendar section
- Team member carousel
- Sponsor showcase
- Horizontally scrollable sponsor and community video section
- Contact form and Instagram link
- Responsive layouts for desktop and mobile devices

## Tech Stack

- React 19
- JavaScript
- CSS
- Vite
- Vercel

## Running Locally

The React application lives in the `frontend` directory.

```bash
cd frontend
npm install
npm run dev
```

Vite will start the local development server and print the local URL in the terminal.

## Production Build

```bash
cd frontend
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
